# PvZ Asset Browser

A standalone LibGDX desktop application for viewing and testing PAM animations using the `libpvz` library.

## Building and Running

### Prerequisites
- JDK 17 or higher

### Run the Application
```bash
./gradlew run
```

### Build
```bash
./gradlew build
```
